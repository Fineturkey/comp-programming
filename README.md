# Competitive programming

Practice solutions for AtCoder, Codeforces, and Kattis.

- `atcoder/`: AtCoder exercises and contests
- `codeforces/`: Codeforces exercises and contests
- `kattis/`: Kattis work, including `kattis/practice/`

One Git repository manages all folders. Original commit histories are retained
through merge commits and `archive/` branches. Local source edits were
preserved during consolidation. Existing exercises may be unfinished.

Compile and run individual solutions from their own folders. Existing editor
settings are preserved within each platform folder. New compiled executables
are ignored; binaries already tracked in the original repositories remain
preserved. No solutions were rewritten or judged during consolidation.
