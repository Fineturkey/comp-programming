## Run a solution

Each program is a standalone exercise. Compile the file you want to try with a
C++ compiler, then supply the input described in its problem statement.

For example, in a Windows terminal with `g++` available, replace the placeholder
path below with the file you want to run:

```powershell
g++ -std=c++17 -O2 -Wall "path/to/solution.cpp" -o solution.exe
.\solution.exe
```

Platform folders also retain their existing VS Code settings. New `.exe`, `.o`,
and `.obj` build outputs are ignored by Git.

## About this collection

This is a learning workspace: some files are finished solutions, while others
are experiments or work in progress. Their presence here does not imply an
accepted submission.

The former AtCoder, Codeforces, Kattis, and practice repositories are consolidated
here as ordinary folders, with their commit histories retained. Everything can
be cloned together; no submodule setup is needed.
